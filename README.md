# 🏠 Virtual Interior Design & Budget Studio

An interactive Python application built with Streamlit for planning room makeovers, exploring curated design aesthetics, and estimating renovation costs instantly.

## 🚀 Live Demo
Access the live web app here: [Interior Design Studio](https://interior-designing-a2cvmfzj4stm3abzw4gys.streamlit.app/)

## ✨ Key Features
- **Style Guide & Palette Explorer:** View curated color hex codes and design descriptions.
- **Room Elements Checklist:** Interactive decor checklist for Living Rooms, Bedrooms, Kitchens, and more.
- **Dynamic Cost Estimator:** Real-time budget calculation based on room square footage.

## 🛠️ Built With
- **Python 3**
- **Streamlit**
- **Pandas & Pillow**
